# 예시 2. 달리기 기록 앱

[앱 기획 표준 v0.1](../SPEC.md) 로 달리기 기록 앱을 적은 예시다. [예시 1 레시피 앱](recipe-app.md) 이 서버에서 받아 보여 주는 앱이라면, 이 앱은 기기에 저장한 값이 기준이고 화면이 꺼져 있어도 일이 계속되는 앱이다. 같은 낱말로 성격이 다른 앱도 적을 수 있는지 보려고 골랐다. 지어낸 앱이고 서버 주소도 가짜다.

예시 1에 없던 것이 넷 들어 있다. 여러 화면이 값을 같이 쓰는 `흐름`, 위치와 권한처럼 기기가 주는 값, 미룰 수 없는 백그라운드 작업과 진행 알림, 홈 화면 위젯이다. 아직 못 정한 것을 적는 `미정` 도 하나 있다.

```bash
python3 tools/appspec_check.py examples/running-app.md
```

## 앱과 소스

```yaml
앱:
  이름: 예시 달리기 기록 앱
  설명:
    - 달린 거리와 시간을 기록하고 지난 기록을 모아 보는 앱
    - 연결이 없어도 기록할 수 있고, 연결되면 서버에 올린다
    - 예시를 짧게 하려고 로그인은 뺐다
  시작 화면: 기록 목록
  탭:
    - 기록 목록
    - 설정
  기본:
    경우:
      로딩: 가운데에 진행 표시를 보여 준다
      오류: 안내 문구와 다시 시도 버튼을 보여 준다
    요청 실패:
      - 안내: 잠시 후 다시 시도해 주세요

소스:
  네트워크:
    기록 서버:
      주소: https://run.example.com
      인증: 없음
      문서: https://run.example.com/docs
  디스크:
    앱 디비:
      종류: 디비
    설정 저장소:
      종류: 설정
```

```yaml
    값: 허용, 거부, 아직 묻지 않음

    기능: 알림 권한
  현재 위치:
    값: 위도와 경도
    소스: 기기
    기능: 위치(GPS)
```

```yaml
  이번 주 위젯:

    설명: 홈 화면에 두는 작은 위젯. 이번 주에 달린 거리와 목표를 보여 준다. 달리기를 저장할 때와 날짜가 바뀔 때 다시 그린다
    컴포넌트:
      거리:
        표시:

        동작:

            한다:
```

## 백그라운드 작업과 알림

```yaml
백그라운드 작업:
  위치 기록:
    설명:
      - 달리는 동안 화면을 꺼도, 다른 앱을 써도 계속 위치를 기록한다
      - 시스템이 앱 프로세스를 종료한 사이의 위치는 기록되지 않는다
      - 거리는 이어진 두 위치 사이의 직선거리를 더한 값이다. 일시정지 중에는 거리와 시간을 세지 않는다
      - 알림 권한이 거부여도 달리기는 시작한다. 진행 알림만 보이지 않는다
    언제: 달리기 준비에서 기록을 시작해서 예약했을 때
    미뤄도 됨: 아니오
    진행 알림: 달리기 진행 알림
    조건:
      - 위치 권한이 항상 허용이거나 앱을 쓰는 동안만 허용이다
    한다:
      - 5초마다 현재 위치를 읽어 진행 중인 달리기의 지나온 위치 목록에 더하고 거리를 다시 계산한다
      - 진행 중인 달리기.일시정지 여부가 예이면 위치를 더하지 않는다
    다시 시도: 시스템이 앱 프로세스를 종료했으면 진행 중인 달리기.끝냄 여부가 아니오인 동안 다시 시작한다
    겹치면: 건너뜀
  기록 올리기:
    설명: 기기에 저장한 달리기 가운데 서버에 올리지 않은 것을 올린다
    언제:
      - 달리기 결과에서 저장해서 예약했을 때
      - 네트워크가 다시 연결될 때
    미뤄도 됨: 예
    조건:
      - 네트워크에 연결돼 있다
    한다:
      - 요청: POST /runs (아직 올리지 않은 달리기를 하나씩)
        성공하면:
          - 변경: 달리기 기록
            값: 올라간 달리기의 서버에 올렸는지를 예로 바꾼다
    다시 시도: 간격을 늘려 가며 성공할 때까지
    겹치면: 건너뜀
  주간 목표 알림 보내기:
    설명: 일요일 저녁에 이번 주 목표를 못 채웠으면 알려 준다
    언제: 매주 일요일 저녁 8시쯤
    미뤄도 됨: 예
    조건:
      - 주간 알림 받기가 예다
      - 이번 주 달린 거리가 주간 목표 거리보다 적다
    한다:
      - 알림: 주간 목표 알림
        넘기는 값:
          남은 거리: 주간 목표 거리에서 이번 주 달린 거리를 뺀 값
    다시 시도: 안 함
    겹치면: 건너뜀

알림:
  달리기 진행 알림:
    설명: 위치 기록이 도는 동안 계속 떠 있다. 사용자가 밀어서 지울 수 없다
    보내는 곳: 앱
    분류: 달리기 중
    중요도: 낮음
    제목: 달리는 중
    본문: 지금까지 달린 거리와 시간을 보여 주고 1초마다 고친다
    앱을 보고 있을 때: 그대로 둔다
    동작:
      달리기 화면 열기:
        언제: 탭
        한다:
          - 이동: 달리기 중
  주간 목표 알림:
    보내는 곳: 앱
    받는 값:
      - 남은 거리
    분류: 목표 알림
    중요도: 보통
    제목: 이번 주 목표까지 조금 남았어요
    본문: 받은 남은 거리를 넣어 몇 km 남았는지 보여 준다
    앱을 보고 있을 때: 띄우지 않는다

        언제: 탭
        한다:
          - 이동: 달리기 준비
```
